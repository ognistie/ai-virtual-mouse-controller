Instalação, requisitos, gestos, atalhos e ajustes finos para dominar o controle gestual.

Requisitos

  • Python 3.11+
  • Windows 10/11
  • Webcam 720p+
  • 4GB RAM mínimo
  • Ambiente com boa iluminação

Profiles

Smooth

Equilíbrio geral.

Precise

Alvos pequenos.

Stable

Máxima filtragem.

// INSTALL

instalação limpa

Cole os comandos no terminal dentro da pasta onde quer guardar o projeto.

powershell
git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
cd ai-virtual-mouse-controller
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py

atalhos de operação

TeclaFunção
SAbre ou fecha painel de configurações.

1-4Alterna entre profiles.
ALiga/desliga aim assist.
KLiga/desliga sticky targeting.
ESCSai do programa.

// TROUBLESHOOT

quando algo falhar

Webcam não abre

Feche Teams, Zoom, OBS e verifique permissões de câmera no Windows.

Cursor tremendo

Use o profile Stable ou aumente Smoothness no painel.

Clique falhando

Melhore iluminação e mantenha a mão mais frontal para a webcam.
