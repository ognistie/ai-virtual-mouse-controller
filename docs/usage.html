Guia detalhado

Instale, execute e controle pela mão.

Documentação passo a passo para preparar o ambiente, executar o projeto localmente e dominar cada gesto reconhecido pelo sistema. Recomendado para a primeira execução.

Requisitos

Antes de começar.

Garanta que o ambiente atende a estes requisitos mínimos. Eles foram validados em Windows 10 e 11 com hardware moderno padrão.

01

Python 3.11 ou 3.12

Versões anteriores ou superiores podem apresentar incompatibilidade com o MediaPipe.

02

Webcam funcional

Integrada ou USB, preferencialmente com resolução de 720p ou superior.

03

Iluminação adequada

Ambientes bem iluminados aumentam a confiança do tracking e reduzem ruído.

04

Terminal moderno

PowerShell, CMD ou terminal integrado do VS Code. macOS e Linux suportados.

Instalação

Comandos completos.

Execute o bloco abaixo na pasta onde deseja manter o projeto. Cada comando é independente e pode ser revisado individualmente.

powershell 
git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
cd ai-virtual-mouse-controller
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r requirements.txt
python main.py
Como executar os gestos

Aprenda o vocabulário gestual.

Cada gesto foi desenhado para ser distinguível por uma câmera comum em iluminação convencional. Pratique em frente ao espelho da janela compacta antes de utilizar em aplicações reais.

01

Mover o cursor

Abra a mão com a palma voltada para a câmera. Movimentos lentos resultam em controle mais preciso; movimentos amplos cobrem maior distância na tela. O cursor segue a base do dedo médio para evitar saltos no momento do clique.

02

Clique esquerdo

Encoste rapidamente o polegar no indicador, formando uma pinça. O clique acontece no instante exato do toque entre os dedos, com feedback imediato e sem latência perceptível.

03

Clique direito

Encoste o polegar no dedo médio, mantendo o indicador estendido. Esse gesto aciona o menu de contexto do sistema operacional, sem ambiguidade com o clique esquerdo.

04

Duplo clique

Faça o sinal de paz com indicador e dedo médio. Mantenha o gesto por aproximadamente 500 ms para confirmar a intenção e disparar o duplo clique nativo do sistema.

05

Pausar o cursor

Feche a mão em punho para congelar instantaneamente a posição do cursor. Útil para reposicionar a mão sem deslocar o ponteiro, especialmente ao alternar entre regiões distantes da tela.
