// guia de uso

instale e controle

Siga os passos abaixo para instalar o projeto, executar localmente e entender como realizar cada gesto na frente da webcam.

// requisitos

antes de começar

01

Python

Use Python 3.11 ou superior.

02

Webcam

Use webcam integrada ou USB, preferencialmente 720p ou 1080p.

03

Ambiente

Use boa iluminação para melhorar o rastreamento da mão.

04

Terminal

Execute os comandos pelo PowerShell, CMD ou terminal do VS Code.

// instalação

comandos

Copie e execute estes comandos na pasta onde deseja salvar o projeto.

powershell 
git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
cd ai-virtual-mouse-controller
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py

// como fazer os gestos

aprenda os gestos

Mover cursor

Abra a mão com a palma voltada para a câmera. Movimente a mão lentamente para guiar o cursor.

Clique esquerdo

Encoste o polegar no indicador. O clique acontece no momento do toque entre os dedos.

Clique direito

Encoste o polegar no dedo médio. Esse gesto abre o menu de contexto.

Pausar cursor

Feche a mão em punho para congelar temporariamente o cursor e evitar movimentos acidentais.

Duplo clique

Faça o sinal de paz com indicador e dedo médio. Mantenha o gesto por um instante para executar o duplo clique.
