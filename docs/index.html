02 · Conceito

Uma nova camada entre mão, câmera e sistema.

Três subsistemas trabalham em sequência — capturando, interpretando e traduzindo gestos em ações no sistema operacional.

VER

Capturar

O stream da webcam é processado pelo MediaPipe Hands, que detecta 21 landmarks por frame com baixa latência na CPU.

webcam · 21 landmarks/frame
ENTENDER

Interpretar

Landmarks alimentam uma máquina de estados de gestos. Distâncias, ângulos e velocidades dirigem a classificação com debounce e gating de confiança.

máquina de estados · 6 gestos
AGIR

Executar

Gestos confirmados se traduzem em eventos do sistema — movimento de cursor, cliques, arrastes e pausas entregues via pyautogui.

pyautogui · comandos de cursor
03 · Capacidades

Feito para interação real.

Um conjunto focado de gestos e comportamentos — cada um ajustado para controle de baixa latência sem sacrificar precisão.

cursor

Controle do cursor

Move o cursor do sistema traduzindo suavemente a posição da mão, com filtragem adaptativa e zona morta.

click

Clique esquerdo

Gesto de pinça entre polegar e indicador detecta a intenção via velocidade e threshold de contato.

right_click

Clique direito

Pinça polegar-médio com guard do indicador isola a intenção de menu de contexto do clique normal.

drag

Arrastar e soltar

Pinça sustentada além do hold threshold entra em modo de arrasto, soltando ao abrir a mão.

double_click

Duplo clique

Sinal de paz dispara um duplo clique preciso com intervalo sintético reconhecido pelo SO nativo.

pause

Gesto de pausa

Punho fechado congela o cursor — útil para leitura estável ou reposicionamento da mão.

overlay

Mão holográfica

Overlay de mesh 3D renderizado com ModernGL — palma anatômica, dedos e polegar rastreados em tempo real.

smoothing

Rastreamento suave

Filtro OneEuro adapta à velocidade do movimento — estável quando parado, responsivo quando se move.

cpu

Sem GPU

GPU não é necessária. O modelo lite do MediaPipe entrega rastreamento a 60 fps em CPUs modernas.

04 · Interface Holográfica

A mão holográfica transforma rastreamento invisível em uma interface visível.

Uma segunda camada visual que segue os mesmos 21 landmarks que o sistema usa para interpretar seus gestos. Renderizada em 3D com ModernGL, a mão holográfica é anatomicamente contínua — palma fundida com os dedos, polegar embutido no thenar, curvas orgânicas em cada articulação.

  • render Mesh 3D via ModernGL + shaders GLSL. VBOs persistentes, cache de mesh, caps hemisféricos nos dedos.
  • material Corpo azul profundo com rim ciano via fresnel — visível em qualquer fundo, claro ou escuro.
  • anatomia Palma em superfície lofted, dedos com seção elíptica, knuckle bulge no PIP, fusão com a thenar.
  • overlay Janela transparente fullscreen, click-through nativo, opcional via a tecla H.

06 · Instalar

Rode localmente em minutos.

Clone, instale as dependências e inicie o controller. Funciona no Windows, macOS e Linux.

  • Python 3.10 ou superior
  • Webcam (integrada ou USB)
  • 2GB de RAM, CPU moderna
  • GPU não é necessária
$ git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
$ cd ai-virtual-mouse-controller
$ python -m venv .venv
$ .venv\Scripts\activate
$ pip install -r requirements.txt
$ python main.py
$ git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
$ cd ai-virtual-mouse-controller
$ python3 -m venv .venv
$ source .venv/bin/activate
$ pip install -r requirements.txt
$ python main.py
