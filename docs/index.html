02 · Concept

A new layer between hand, camera and OS.

Three subsystems work in sequence — capturing, interpreting and translating gestures into system-level actions.

see

Capture

The webcam stream is processed by MediaPipe Hands, which detects 21 landmarks per frame at low latency on CPU.

webcam · 21 landmarks/frame
understand

Interpret

Landmarks feed a gesture state machine. Distances, angles and velocities drive classification with debounce and confidence gating.

state machine · 6 gestures
act

Execute

Confirmed gestures translate into operating system events — cursor movement, clicks, drags and pauses delivered through pyautogui.

pyautogui · cursor commands
03 · Capabilities

Built for real interaction.

A focused set of gestures and behaviors — each one tuned for low-latency control without sacrificing precision.

cursor

Cursor control

Move the system cursor by smoothly translating hand position, with adaptive smoothing and dead-zone filtering.

click

Left click

Pinch gesture between thumb and index detects intent through velocity and contact threshold.

right_click

Right click

Thumb-to-middle pinch with index guard isolates context menu intent from regular clicking.

drag

Drag and drop

Sustained pinch lasting beyond the hold threshold enters drag mode, releasing on open hand.

double_click

Double click

Peace sign gesture triggers a precise double-click with synthetic interval for native OS recognition.

pause

Pause gesture

Closed fist freezes the cursor in place — useful for stable reading or repositioning the hand.

overlay

Holographic hand

3D mesh overlay rendered with ModernGL — anatomical palm, fingers and thumb tracked in real-time.

smoothing

Smooth tracking

OneEuro filter adapts to motion speed — stable when still, responsive when moving, never laggy.

cpu

CPU-friendly

No GPU required. MediaPipe lite model handles 60 fps tracking on modern CPUs.

04 · Holographic Interface

The holographic hand turns invisible tracking into a visible interface.

A second visual layer that follows the same 21 landmarks the system uses to interpret your gestures. Rendered in 3D with ModernGL, the holographic hand is anatomically continuous — palm fused with fingers, thumb embedded in the thenar, organic curves through every joint.

  • render 3D mesh via ModernGL + GLSL shaders. Persistent VBOs, mesh cache, hemisphere finger caps.
  • material Deep blue body with cyan rim through fresnel — visible on any background, dark or light.
  • anatomy Lofted palm surface, elliptical finger cross-sections, knuckle bulge at PIP, thenar fusion.
  • overlay Fullscreen transparent window, click-through native, optional via the H key.

06 · Install

Run locally in minutes.

Clone, install dependencies, and start the controller. Works on Windows, macOS and Linux.

  • Python 3.10 or newer
  • Webcam (built-in or USB)
  • 2GB RAM, modern CPU
  • No GPU required
$ git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
$ cd ai-virtual-mouse-controller
$ python -m venv .venv
$ .venv\Scripts\activate
$ pip install -r requirements.txt
$ python main.py
$ git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
$ cd ai-virtual-mouse-controller
$ python3 -m venv .venv
$ source .venv/bin/activate
$ pip install -r requirements.txt
$ python main.py
