O projeto

Uma interface gestual simples, construída sobre visão computacional.

A webcam identifica a posição da mão. O sistema interpreta a postura e converte a intenção em eventos reais do sistema operacional, como mover, clicar, arrastar e avançar slides.

Tudo acontece localmente, sem conta, servidor externo ou envio do vídeo para a nuvem. O projeto é aberto e pode ser ajustado para diferentes câmeras, telas e formas de interação.

Cada parte da stack tem uma função clara.

Uma arquitetura local e modular separa captura, interpretação e execução. Isso mantém a interação responsiva e facilita testes e evolução.

Como funciona

Da câmera ao comando em três etapas.

  1. 1

    Capturar

    A webcam fornece frames contínuos, processados localmente pelo OpenCV.

  2. 2

    Interpretar

    Os landmarks formam gestos estáveis, filtrados por confiança e contexto.

  3. 3

    Executar

    A intenção confirmada vira movimento, clique ou comando de teclado.

Gestos

Movimentos fáceis de aprender e distinguir.

Cada gesto foi escolhido para reduzir ativações acidentais e manter o uso confortável ao longo de uma sessão.

01

Mover

Mão aberta acompanha o cursor com suavização adaptativa.

02

Clicar

Pinça rápida entre polegar e indicador.

03

Clique direito

Polegar e médio acionam o menu de contexto.

04

Duplo clique

O sinal de paz confirma uma abertura precisa.

05

Pausar

Punho fechado congela o cursor imediatamente.

Instalação

Comece com dois comandos.

Requer Python 3.11, 3.12 ou 3.13 e uma webcam. A instalação principal não exige GPU.

  • Windows, macOS ou Linux X11
  • Processamento executado localmente
  • Overlay 3D incluído e ativado sob demanda
pip install ai-virtual-mouse-controller
avmc
git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
cd ai-virtual-mouse-controller
