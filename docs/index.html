Visão geral

Uma interface natural entre você e o computador.

O projeto explora um novo paradigma de interação humano-máquina: substituir o periférico físico por gestos intencionais, capturados em tempo real e convertidos em ações precisas no sistema operacional. Tudo isso rodando em CPU comum, com qualidade de input comparável a um mouse físico.

Sem hardware extra

Usa qualquer webcam integrada ou USB. Dispensa luvas, sensores e câmeras de profundidade. O modelo roda em CPU.

Latência mínima

Press-to-click por detecção de borda no shape, filtragem OneEuro e threading da câmera mantêm ~58 FPS estáveis.

Calibração em runtime

Quatro perfis pré-definidos e seis sliders ajustáveis em tempo de execução, sem necessidade de reiniciar a aplicação.

Janela compacta

Interface 480×270 always-on-top no canto da tela, no estilo de streamers. Não atrapalha o fluxo de trabalho.

Aim assist inteligente

Desaceleração proporcional em alvos pequenos e sticky targeting para reduzir overshoot em botões e links.

Arquitetura limpa

Separação clara entre core (algoritmos) e services (orquestração), totalmente documentada e testável.

Como funciona

Da câmera ao clique em milissegundos.

Cada frame capturado pela webcam atravessa um pipeline assíncrono composto por cinco estágios. O design prioriza estabilidade de FPS, baixa latência e robustez ao tremor natural da mão.

  • 01 · Captura assíncrona Thread dedicada lê frames da webcam com buffer mínimo, descartando frames atrasados para manter a taxa estável.
  • 02 · Detecção de landmarks MediaPipe Hands extrai 21 pontos 3D da mão a cada frame, com confiança individual por landmark.
  • 03 · Reconhecimento gestual State machine com histerese de 2/3 frames classifica o gesto em curso e elimina cliques fantasma.
  • 04 · Suavização adaptativa Filtro OneEuro reduz tremor em repouso e libera resposta rápida em movimento contínuo.
  • 05 · Comando do sistema PyAutoGUI traduz a intenção em movimento absoluto do cursor e em cliques nativos do sistema operacional.

Gestos

O vocabulário gestual.

Seis gestos canônicos cobrem todas as operações básicas do cursor. A escolha foi guiada por ergonomia: cada movimento foi desenhado para minimizar fadiga em sessões longas e maximizar distância visual entre estados.

01

Mover o cursor

Mão aberta com a palma voltada para a câmera. O cursor segue a base do dedo médio (landmark 9), evitando saltos no instante do clique.

02

Clique esquerdo

Pinça curta entre polegar e indicador. A detecção ocorre por edge detection no shape, garantindo feedback imediato no momento do toque.

03

Clique direito

Pinça entre polegar e dedo médio, com indicador estendido. Aciona o menu de contexto sem ambiguidade com o clique esquerdo.

04

Duplo clique

Indicador e médio formando o sinal de paz, mantidos por aproximadamente 500 ms. Tempo dedicado evita ativação acidental.

05

Pausar

Punho fechado congela o cursor instantaneamente. Útil ao ajustar a posição da mão sem deslocar o ponteiro na tela.

06

Arrastar (drag)

Pinça polegar–indicador mantida por aproximadamente 3 segundos inicia o modo arrastar. Abrir a mão libera o item no destino.

  • Funciona com janelas, ícones e seleção de texto.
  • Indicador visual na janela confirma o estado ativo.
  • Cancelamento automático após 5 segundos sem movimento.
Guia de instalação

Configure o projeto em menos de cinco minutos.

O processo é direto: prepare o ambiente, clone o repositório, instale as dependências e execute o ponto de entrada. Os passos abaixo cobrem a configuração recomendada em Windows 10 ou 11.

Pré-requisitos

  • 01
    Python 3.11 ou 3.12 Versões 3.13 ou superiores ainda não são suportadas pelo MediaPipe.
  • 02
    Webcam funcional Integrada ou USB, com resolução mínima de 720p para tracking estável.
  • 03
    Git instalado Necessário para clonar o repositório. Alternativamente, baixe o ZIP do GitHub.
  • 04
    Windows 10 ou 11 Plataforma principal de teste. macOS e Linux funcionam via fallback do OpenCV.
  • 05
    Iluminação adequada Ambientes bem iluminados melhoram a confiança de detecção do MediaPipe.
Passo 01

Clone o repositório oficial

Abra um terminal (PowerShell, CMD ou terminal integrado do VS Code) na pasta onde deseja manter o projeto e execute:

terminal 
git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
cd ai-virtual-mouse-controller
Passo 02

Crie e ative o ambiente virtual

O ambiente virtual isola as dependências do projeto e evita conflitos com outras instalações Python no sistema:

powershell 
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

No CMD use .\.venv\Scripts\activate.bat. Em macOS ou Linux, utilize source .venv/bin/activate.

Passo 03

Instale as dependências

O arquivo requirements.txt contém todas as bibliotecas necessárias, com versões testadas e fixadas:

pip 
pip install --upgrade pip
pip install -r requirements.txt
Passo 04

Execute a aplicação

Com o ambiente preparado, inicie o ponto de entrada do projeto. Uma janela compacta de 480×270 aparecerá no canto inferior direito da tela:

python 
python main.py

Posicione a mão a aproximadamente 50 cm da câmera, com a palma voltada para a frente. Pressione ESC a qualquer momento para encerrar.

Solução de problemas

Quando algo não funciona como esperado.

Mapeamos os incidentes mais frequentes em instalação e execução, junto com a causa raiz e o procedimento de resolução. Em caso de dúvida persistente, abra uma issue no repositório com a saída completa do terminal.

Instalação Erro no pip install mediapipe ou ERROR: Could not find a version that satisfies the requirement mediapipe

Causa: a versão do Python instalada é incompatível com o MediaPipe. A biblioteca atualmente suporta apenas Python 3.8 a 3.12.

Como resolver:

  1. Verifique a versão ativa com python --version.
  2. Instale Python 3.11 ou 3.12 a partir do site oficial python.org.
  3. Recrie o ambiente virtual apontando para a versão correta: py -3.11 -m venv .venv.
  4. Ative o novo ambiente e execute pip install -r requirements.txt novamente.
Execução ModuleNotFoundError: No module named 'cv2' ou 'mediapipe'

Causa: o ambiente virtual não está ativo, ou as dependências foram instaladas em outro interpretador Python.

Como resolver:

  1. Confirme que o prompt do terminal exibe (.venv) antes do diretório.
  2. Caso não exiba, reative o ambiente com .\.venv\Scripts\Activate.ps1.
  3. Reexecute pip install -r requirements.txt dentro do ambiente.
  4. Valide a instalação com python -c "import cv2, mediapipe; print('ok')".
Webcam A janela abre preta ou exibe Cannot open camera

Causa: outro aplicativo está utilizando a webcam, ou o sistema bloqueou o acesso por configurações de privacidade.

Como resolver:

  1. Encerre programas que possam estar utilizando a câmera: Microsoft Teams, Zoom, Discord, OBS, navegadores com chamadas ativas.
  2. No Windows, acesse Configurações → Privacidade e segurança → Câmera e habilite o acesso para aplicativos desktop.
  3. Se houver mais de uma câmera, altere CAMERA_INDEX em config.py (geralmente 0, 1 ou 2).
  4. Reinicie a aplicação após cada alteração.
PowerShell Activate.ps1 cannot be loaded because running scripts is disabled

Causa: a política de execução padrão do PowerShell impede a execução de scripts não assinados, incluindo o script de ativação do venv.

Como resolver:

  1. Abra o PowerShell como usuário comum e execute:
powershell 
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Confirme com S e reabra o terminal. A política altera somente o seu usuário, mantendo o sistema seguro.

Performance FPS abaixo de 30 ou atrasos perceptíveis entre o gesto e o cursor

Causa: o hardware está abaixo do recomendado ou a configuração do modelo está alta demais para o processador disponível.

Como resolver:

  1. Edite config.py e altere MODEL_COMPLEXITY = 1 para MODEL_COMPLEXITY = 0.
  2. Reduza a resolução de captura: CAMERA_WIDTH = 640 e CAMERA_HEIGHT = 360.
  3. Feche aplicações pesadas em segundo plano (navegadores com muitas abas, IDEs, jogos).
  4. Conecte o notebook na tomada para evitar throttling térmico em modo bateria.
Precisão O cursor treme parado, oscila ou faz cliques indesejados

Causa: ruído no tracking causado por iluminação irregular, fundo carregado ou perfil de suavização inadequado.

Como resolver:

  1. Pressione S para abrir o painel e selecione o perfil stable.
  2. Aumente o slider de Smoothness em até 30%.
  3. Eleve o Pinch threshold caso ocorram cliques fantasma.
  4. Reposicione a câmera para enquadrar a mão com fundo neutro e contraste claro.
  5. Garanta iluminação frontal — evite luz contra a câmera.
PyAutoGUI pyautogui.FailSafeException ao mover o cursor para o canto

Causa: o PyAutoGUI possui um mecanismo de segurança que interrompe a execução quando o cursor atinge o canto superior esquerdo da tela.

Como resolver:

  1. O comportamento é intencional e protege contra loops descontrolados.
  2. Reposicione a mão na área central da câmera e reinicie a aplicação.
  3. Se necessário desativar o failsafe (não recomendado), adicione pyautogui.FAILSAFE = False em main.py.
MediaPipe AttributeError: module 'mediapipe.solutions' has no attribute 'hands'

Causa: versões 0.11 ou superiores do MediaPipe removeram a API legada mp.solutions.hands utilizada pelo projeto.

Como resolver:

  1. Force a instalação de uma versão compatível:
pip 
pip install "mediapipe>=0.10.9,<0.11"

Confirme com pip show mediapipe que a versão instalada está entre 0.10.9 e 0.10.x.

Git git: command not found ou 'git' is not recognized

Causa: o Git não está instalado no sistema ou não está incluído na variável de ambiente PATH.

Como resolver:

  1. Faça o download em git-scm.com e execute o instalador com as opções padrão.
  2. Reabra o terminal para que a nova variável de ambiente seja carregada.
  3. Alternativa: baixe o projeto como arquivo ZIP diretamente pela página do repositório no GitHub.
