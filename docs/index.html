01 uma webcam · duas mãos · zero hardware

Pare de procurar o mouse. Você tem mãos.

Esse projeto pega o stream da sua webcam, joga em um modelo de visão computacional e transforma cada microgesto da mão em comando real do cursor. Mover, clicar, arrastar, pausar. Sem hardware extra. Sem GPU. Sem treinar modelo.

É menos mágico do que parece. E muito mais útil do que aparenta.

02 manifesto curto

Três coisas que esse projeto tenta se recusa a ser.

  1. 01.

    “Mais uma demo bonita.”

    A maioria dos projetos de hand tracking morre no GIF do README. Esse continua de pé quando a luz está ruim, quando a câmera está suja, e quando a mão já cansou de demonstrar para você. ↳ testado em sessões reais, não em vídeo promocional.

  2. 02.

    “Dependente de GPU.”

    Roda a 58 FPS estáveis no processador que você já tem. Sem CUDA, sem placa dedicada, sem tensorrt. Se o seu notebook abre o Chrome com vinte abas, ele dá conta disso aqui também.

  3. 03.

    “Mais um wrapper de exemplo.”

    State machine própria, filtro adaptativo OneEuro implementado do paper original, decisões de âncora de cursor defendidas linha a linha. Não é wrapper. É opinião feita em código.

03 como funciona

Da palma da sua mão
até o sistema operacional
em 30 ms.

Cada frame da webcam passa por cinco estágios. Tudo assíncrono, tudo em CPU. O design prioriza FPS estável, latência baixa e sobrevivência a tremor natural da mão.

  1. passo 1

    Captura assíncrona

    Thread dedicada lê a webcam com buffer mínimo e descarta frames atrasados. Não dá pra trabalhar com 25 FPS bloqueante.

  2. passo 2

    MediaPipe Hands

    21 pontos 3D da mão, com confiança por landmark. O modelo é da Google, a interpretação é nossa.

  3. passo 3

    State machine de gestos

    Histerese de 2/3 frames na entrada e saída. Sem ela, qualquer ruído vira clique fantasma.

  4. passo 4

    Filtro OneEuro

    Filtragem agressiva em repouso, liberada em movimento. EMA com α fixo é solução preguiçosa. Recomendamos não usar.

  5. passo 5

    PyAutoGUI

    Comando absoluto de cursor. Press-to-click por edge detection no shape. O clique acontece no instante do toque dos dedos.

※ nota técnica do autor

O cursor segue o landmark 9 (base do dedo médio) — não a ponta do indicador. A ponta do indicador mente no momento do clique: ela se move quando os dedos se aproximam pra fazer a pinça, e isso faz o cursor pular bem no momento em que você quer precisão. Usar a base do médio resolve isso sem firula.

04 o vocabulário

Seis gestos.
Foi exatamente o que coube.

Cada um foi escolhido com dois critérios: deve sobreviver ao tremor da sua mão e não pode ser confundido com outro. Se você está pensando “e o gesto X”, a resposta é provavelmente: testamos, falhou, fora.

01

Mover

Mão aberta, palma na câmera. O cursor segue um ponto estável da mão (a famosa base do médio). Movimentos lentos = controle fino. Amplos = travessia rápida da tela.

gesto padrão · sempre ativo
02

Clique esquerdo

Encosta o polegar no indicador. O clique acontece no toque, não no release. Diferença prática: zero latência percebida.

edge detection · instantâneo
03

Clique direito

Polegar encosta no dedo médio, com indicador estendido. Abre o menu de contexto sem confundir com o clique esquerdo. O indicador é a chave da desambiguação.

menu de contexto
04

Duplo clique

Sinal de paz mantido por meio segundo. O delay é proposital: tem que ser intencional, senão dispara sozinho enquanto você só queria apontar.

~500 ms de hold
05

Pausar

Punho fechado congela o cursor. Útil para reposicionar a mão (e o braço) sem o cursor surfar pela tela junto. Soltar o punho retoma o tracking.

freeze instantâneo
06

Arrastar (o bônus)

Pinça polegar–indicador mantida por 1.5 segundos inicia o modo arrastar. Funciona com janelas, ícones, seleção de texto. Abrir a mão libera no destino. Não tem cursor de seta puxando — tem a sua mão puxando.

hold de 1.5s · indicador visual ativo
05 novo · holograma da mão

A sua mão,
na tela.

Aperta H em runtime e uma mão holográfica azul-ciano aparece sobreposta ao desktop. Acompanha cada movimento da sua mão real captado pela webcam. Click-through nativo — não bloqueia nenhuma interação.

  • OneEuro per landmark. Mesmo filtro adaptativo do cursor. Estável parado, responsivo em movimento.
  • Click bursts no pinch. Anel ciano expande no ponto exato onde os dedos se tocaram. Cyan = clique esquerdo, azul = direito.
  • Pseudo-3D com gradient direcional. Luz vinda do canto superior-esquerdo + curvas Catmull-Rom + wireframe interno. Volume sem OpenGL.
  • ~0.4 ms por frame. Negligenciável no budget. Roda em 24 FPS dedicado, não compete com a inferência.
opcional · liga e desliga com H requer pip install PySide6
holograma · azul ciano
click-through · 30 FPS · ~0.4 ms
06 manual de instalação

Cinco minutos.
Quatro passos.
Um terminal.

antes de começar, garante que:

  • ✓ tem Python 3.11 ou 3.12 (3.13+ ainda não rola com MediaPipe)
  • ✓ tem uma webcam (qualquer uma, sério)
  • ✓ tem Git instalado (ou baixa o ZIP do GitHub, vai)
  • ✓ tá em Windows 10/11 (macOS/Linux funcionam via fallback)
  • ✓ a iluminação não tá terrível
passo 01

Clone o repositório

Abre um terminal (PowerShell, CMD, terminal do VS Code, tanto faz) na pasta onde quer guardar o projeto.

terminal
git clone https://github.com/ognistie/ai-virtual-mouse-controller.git
cd ai-virtual-mouse-controller
passo 02

Cria o ambiente virtual

Isola as dependências. Evita que esse projeto brigue com outros Python no seu sistema. Se você nunca usou venv, é literalmente uma pastinha local com seu próprio Python.

powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

no CMD: .\.venv\Scripts\activate.bat · no macOS/Linux: source .venv/bin/activate

passo 03

Instala as dependências

Versões fixadas e testadas. Não troca por “última versão” por sua conta — MediaPipe gosta de quebrar API entre minor versions.

pip
pip install --upgrade pip
pip install -r requirements.txt
passo 04

Roda

Uma janela 480×270 abre no canto inferior direito da tela. Coloca a mão a uns 50 cm da câmera, palma pra frente. ESC sai quando você quiser.

07 quando der ruim

E vai dar.
Bom designer reconhece isso.

Mapeamos os incidentes mais comuns, com causa e antídoto. Se nada aqui resolve, abre uma issue no repositório — colado o erro completo do terminal, por favor.

erro 01 · instalação pip install mediapipe falha com Could not find a version that satisfies the requirement

O que está acontecendo: sua versão de Python é nova demais (3.13+) ou velha demais. MediaPipe suporta 3.8 até 3.12 hoje.

Antídoto:

  1. Confere a versão atual: python --version.
  2. Baixa Python 3.11 (estável) do site oficial: python.org/downloads.
  3. Recria o venv apontando pra ela: py -3.11 -m venv .venv.
  4. Reativa e roda o pip install -r requirements.txt de novo.
erro 02 · execução ModuleNotFoundError: No module named 'cv2' ou 'mediapipe'

O que está acontecendo: ou o venv não está ativo, ou as deps foram instaladas em outro Python sem você notar.

Antídoto:

  1. Verifica se o terminal mostra (.venv) antes do diretório. Se não mostra, ative: .\.venv\Scripts\Activate.ps1.
  2. Reroda pip install -r requirements.txt com o venv ativo.
  3. Testa: python -c "import cv2, mediapipe; print('ok')".
erro 03 · webcam A janela abre preta ou Cannot open camera

O que está acontecendo: outro aplicativo está segurando a câmera, ou o Windows bloqueou o acesso por privacidade.

Antídoto:

  1. Fecha Teams, Zoom, Discord, OBS e qualquer aba do navegador em chamada.
  2. Windows: Configurações → Privacidade e segurança → Câmera e libera para apps desktop.
  3. Se você tem mais de uma webcam, muda CAMERA_INDEX no config.py pra 1 ou 2.
erro 04 · powershell Activate.ps1 cannot be loaded because running scripts is disabled

O que está acontecendo: política padrão do PowerShell bloqueia scripts não assinados. Inclui o de ativação do venv.

Antídoto: abre o PowerShell e roda (confirma com S quando perguntar):

powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Altera só o seu usuário. Sistema continua seguro. Reabre o terminal e tenta de novo.

erro 05 · performance FPS abaixo de 30, ou atraso visível entre gesto e cursor

O que está acontecendo: o modelo está configurado em qualidade máxima e o seu CPU não dá conta. Ou está em throttling térmico (notebook na bateria).

Antídoto:

  1. Em config.py, troca MODEL_COMPLEXITY = 1 por MODEL_COMPLEXITY = 0.
  2. Reduz a captura: CAMERA_WIDTH = 640 e CAMERA_HEIGHT = 360.
  3. Conecta o notebook na tomada. Sério, faz diferença.
  4. Fecha Chrome com 80 abas, IDE pesada, joguinho rodando atrás.
erro 06 · precisão O cursor treme parado, oscila, ou faz cliques que você não pediu

O que está acontecendo: ruído no tracking. Geralmente é iluminação ou fundo confuso.

Antídoto:

  1. Aperta S e troca pro perfil stable.
  2. Aumenta o slider de Smoothness em uns 30%.
  3. Sobe o Pinch threshold se está clicando do nada.
  4. Reposiciona a câmera: fundo neutro, luz na sua frente e não atrás.
erro 07 · pyautogui pyautogui.FailSafeException ao mover pro canto

O que está acontecendo: o PyAutoGUI tem um failsafe — se o cursor vai pro canto superior esquerdo, ele aborta. É proposital, protege contra loops descontrolados.

Antídoto: reposiciona a mão no centro da câmera e reinicia. Se você está fazendo desenvolvimento e quer desativar (não recomendado pra uso normal), adiciona pyautogui.FAILSAFE = False no main.py.

erro 08 · mediapipe AttributeError: module 'mediapipe.solutions' has no attribute 'hands'

O que está acontecendo: a partir do MediaPipe 0.11 a API legada mp.solutions.hands foi removida. Você instalou uma versão nova demais.

Antídoto: força a versão certa.

pip
pip install "mediapipe>=0.10.9,<0.11"

Confere com pip show mediapipe.

erro 09 · git 'git' is not recognized ou git: command not found

O que está acontecendo: você não tem Git instalado, ou ele não está no PATH.

Antídoto: baixa em git-scm.com, instala com as opções padrão, reabre o terminal. Alternativa rápida: baixa o ZIP direto da página do GitHub. Funciona igual.

erro 10 · holograma Apertei H e nenhuma mão holográfica aparece

O que está acontecendo: o PySide6 não está instalado. O holograma é opt-in — sem ele, o projeto roda normal, mas a tecla H não tem efeito visual.

Antídoto:

  1. Com o venv ativo: pip install PySide6.
  2. Roda python main.py de novo.
  3. Olha o log do startup. Deve aparecer [AVM] HologramOverlay criado: available=True.
  4. Aperta H. A mão aparece em ~1s.

Se available=False aparecer mesmo com PySide6 instalado, copia o WARNING completo e abre uma issue.
